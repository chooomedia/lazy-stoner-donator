# Lazy Stoner Donator Agent Stack

This directory contains project-specific agent briefs for the `lazy-stoner-donator` static frontend.

## Purpose

Use these agents to improve a values-driven wishlist landing page where success depends on:

- qualified outbound clicks to wishlist, affiliate, or support destinations
- support/share behavior as secondary conversion signals
- clear message match between hero, cards, trust cues, and CTAs

## Primary audience

Values-driven supporters who want to do something meaningful for themselves, for Chris, and for the wider community.

## Working model

Use the lean operating sequence below:

1. `conversion-strategy-agent.md`
2. `message-match-copy-agent.md`
3. `product-proof-agent.md`
4. `release-qa-agent.md`

## Evidence model

- Verified repo state, user-provided sources, reports, and product pages are facts.
- Experimental ideas are allowed, but must always stay labeled as hypotheses.
- Do not invent product facts, metrics, or research findings.

## Stack guardrails

- This project is a static HTML/CSS/JS frontend, not Shopify, SvelteKit, or a backend-heavy app.
- Keep recommendations mobile-first and conversion-oriented.
- Prefer one major conversion variable per iteration.
